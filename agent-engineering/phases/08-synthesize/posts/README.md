# Post Drafts

Drafts of public posts for `asleekgeek.com`, distilled from the curriculum's build work.

Workflow:

1. Write the draft in the Obsidian vault first (where the wikilinks resolve).
2. When ready for review, copy to this directory under a numbered filename.
3. Open a PR; reviewer comments live on the PR, not in the vault.
4. After merge, publish to `asleekgeek.com` via the Sanity / Next.js pipeline.
5. The merged file stays here as the source of truth post-publish.
