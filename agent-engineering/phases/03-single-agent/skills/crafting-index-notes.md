# Crafting Index Notes

## When to propose one

Propose a new index note when you find ≥5 notes that:

- Share a thematic concern (concept, project, paper, person)
- Mostly link to each other but lack a hub
- Don't fit cleanly under an existing index note

## Naming

Use the pattern `<Topic> Index.md`. Examples: `RAG Index.md`, `Skills Index.md`.

## Structure

A new index note should contain:

- One-sentence framing of the topic
- A short, prose introduction (2–4 sentences) that explains why this cluster exists
- A list of the related notes as wikilinks, grouped if natural
- Open questions / known gaps as bullet points

## Anti-patterns

- Do NOT propose an index note for every cluster you find. Only when the hub absence is real.
- Do NOT propose folder reorganisation. The vault is flat by convention.
- Do NOT propose renaming existing notes to "fit" the new index.
