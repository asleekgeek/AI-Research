# Docs

Supplementary documentation for the curriculum's build artifacts. The curriculum *content* (deep-dive markdown, Mermaid diagrams, the conceptual scaffolding) lives in a private Obsidian vault — this directory is for repo-local reference material.

## What's here

- **[`adr/`](./adr/)** — Architecture Decision Records. Why the repo is shaped the way it is.
- (More as the curriculum grows.)

## What's *not* here

The curriculum notes themselves — phase deep-dives, reading lists, post drafts — live in the Obsidian vault under `AI Research/`. That keeps the public repo focused on code while letting the conceptual work stay in the substrate optimised for it (wikilinks, graph view, Mermaid native rendering, daily-note workflow).

When a draft post in `AI Research/` is ready to publish, it migrates from the vault into `posts/` here for review and version control before being pushed to `asleekgeek.com`.
